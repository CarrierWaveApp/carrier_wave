Explore Features is a curated gallery of marquee Carrier Wave features. It gives you a quick pitch for each one, tells you where to find it, and — for experiments — lets you enable it right from the list.

## Getting There

Open Explore Features from:

- **More → Explore Features** in the tab bar More menu
- The **Explore Features** link on the Getting Started card on Home

## What's in the Gallery

Each entry includes:

- **Name and brief description** — a 1–2 sentence explanation of what the feature does and why you might want it
- **"Find it" hint** — where in the app to go (for example, "Logger → RBN command" or "Sessions tab")
- **Maturity badge** — shown only for features still being refined (Beta or Alpha); entries without a badge are fully released
- **Enable toggle** — for experiments that are off by default, an inline toggle so you can turn them on without leaving the gallery

## Feature Entries

The gallery covers approximately 15 marquee features, including:

| Feature | Find it |
|---------|---------|
| Tune In (WebSDR) | Logger → `WEBSDR` command |
| FT8 Suite | FT8 tab |
| Brag Sheet | Sessions → session detail → Share |
| Session Replay | Sessions → session detail → timeline |
| Video Export | Sessions → session detail → Share → Video |
| POTA Awards | Home → POTA Awards card |
| Smart Spots | Settings → Smart Needs |
| Hunter Log | Friends tab |
| CW Transcription | More → Customize Tab Bar → add CW |
| Log Scanning | Logbook toolbar → Scan Handwritten Log |
| Propagation Check | Experiments (enable from here) |
| Weather Radar | Experiments (enable from here) |

## Experiments with Inline Toggles

For hidden experiments, the enable toggle in Explore Features is equivalent to the toggle in **Settings → Experiments**. Enabling a feature here makes it immediately available in the app — no need to navigate to Settings first.
