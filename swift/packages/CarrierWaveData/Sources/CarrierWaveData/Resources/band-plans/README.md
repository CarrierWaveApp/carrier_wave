# Band Plans

Region-aware amateur radio TX-permitted segments consumed by `BandPlan` and
the macro safety gate.

US: ARRL band-plan summary (HF) + 6m/2m/70cm general (FCC). R1/R2/R3: IARU
baseline TX allocations; may be more permissive than any individual country's
license. Authoritative jurisdictional plan lives with each national society.

A future iteration can add country-level overrides (e.g. UK, Germany, Japan,
which have narrower allocations than the R-region union) without changing the
loader API.
