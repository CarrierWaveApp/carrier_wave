Sessions

Activation logger

Start a session and log QSOs live — a redesigned start wizard, mode-default RST, Super Check Partial suggestions, and day-scoped dupe detection.

Spots

Live hunter feed

RBN, POTA, SOTA, WWFF, and cluster spots on the same shared spot engine as iOS, with band / mode / needs filters and an interactive frequency scope.

Tap today’s logged contacts to edit callsign, band, mode, frequency, RST, location, and notes inline — saved straight to the shared store.

Customizable achievement stats across weekly, monthly, and all-time periods, computed by the same engine that powers the iPhone app.

Sync

End-to-end encrypted server sync keeps the same logbook on your phone and the field — with magic-link sign-in that opens straight back into the app.

Installing

  • Android 7.0 (Nougat) or later.
  • Tap the APK to install — your phone will ask you to allow installs from this source the first time. This is expected for a sideloaded beta.
  • Updates are manual for now — download a newer APK from this page and install it over the top; your on-device logbook is preserved.
  • One-time reinstall for 0.7.0. Starting with 0.7.0 the APK is signed with a new release key. Android won’t install it over 0.6.x or earlier, and uninstalling deletes the on-device logbook — so sign in to Carrier Wave Sync first (without Sync, only POTA activations can be exported, from Activations → Export ADIF), uninstall, install 0.7.0, then sign back in. Later updates install over the top as usual.
  • The APK is signed with Carrier Wave’s release key; keep installing builds from here so updates apply cleanly.
