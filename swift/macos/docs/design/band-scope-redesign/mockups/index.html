Band Scope Redesign — Mockups

CWSweep · 2026-04-07 · research notes

Five design directions plus the annotated current state. Each mockup is a static HTML/SVG file at the target laptop size (1392 × 760 pt). Open them standalone in a browser to see the full layout. Read the research notes for the rationale and the recommended build order.

00Current state, annotated

The existing ContestBandScopeView drawn to spec from the code, with the actual pain points highlighted in red callouts. Reference for everything that follows.

01Single-band, refined

Same layout as today, with every interaction pain point fixed in place: cursor crosshair, mini-map, mode-aware snap, keyboard zoom, sub-band shading you can actually see. Lowest-risk shipping path.

02Stacked bands (N1MM-inspired)

Five band columns side by side. Trades the live spectrum for the ability to see five bands at once. The contest situational awareness answer.

03Grid overview (TradingView-inspired)

4 × 3 grid of small per-band cells with density histograms. Click to expand into the main scope. The scanning answer.

04Hybrid: active band + railRECOMMENDED

Big active scope on the left, thin band rail on the right with mults / new / density per band. Smallest delta from today, biggest situational awareness win.

05Multi-VFO + watchlist

Variant 01 plus a second VFO cursor for sub-receiver radios, watch markers, and a recent-frequency history trail. Forward-looking power-user variant.
